SVG XSS — Test clic droit

Mécanisme : Le SVG embarqué dans <img> via data URI est sandboxé à l'affichage. Mais si tu fais clic droit → "Ouvrir l'image dans un nouvel onglet", le navigateur navigue vers la data URI directement — le SVG devient un document à part entière avec scripting actif.
Attendu (navigateurs modernes) : opaque origin → alert s'exécute mais sans accès au document parent. Sur anciens navigateurs : XSS complète.
